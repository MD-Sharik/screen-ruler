MM to Inches: A Quick Reference Table

MD-Sharik August 28, 2026 3 min read

1 inch is defined as exactly 25.4 millimeters — which means 1 millimeter equals exactly 1 ÷ 25.4 ≈ 0.03937 inches. Unlike inches-to-centimeters, this conversion never lands on a clean round number in the other direction, which is exactly why a reference table is more useful here than doing the division in your head.

This comes up constantly outside of pure unit conversion homework: matching a metric bolt to an imperial wrench, checking a 3D-printed part's tolerance, or figuring out which drill bit is closest to a millimeter spec on a datasheet. For that last kind of use, the closest common fractional inch matters more than the decimal — so the table below includes both.

Fractions are rounded to the nearest 1/64 inch, the finest increment most rulers, calipers, and drill bit sets actually use. At small sizes that rounding is proportionally larger — 1mm's nearest 1/64″ is off by about 0.19mm — so treat the fraction column as a practical match, not a precise one.
